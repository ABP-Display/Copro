# Sources de référence complémentaires

Ces dossiers conservent le code GPL réellement installé dans le conteneur
Diacamma de référence, extrait le 13 octobre 2026. Ils ne sont pas chargés par
la nouvelle application Django et ne constituent pas des fonctions déjà portées.
Les notices des auteurs sont conservées dans les fichiers.

- `financial/accounting` et `financial/payoff` : distribution
  `diacamma-financial` 2.7.9.26072908.
- `lucterios-extra/contacts` et `lucterios-extra/mailing` : distribution
  `lucterios-contacts` 2.7.7.26070318.
- `lucterios-extra/documents` : distribution `lucterios-documents`
  2.7.3.25091516.
- Framework de la référence : `lucterios` 2.7.9.26070711.

Les fichiers Python compilés et caches ont été exclus. Le dépôt du module
copropriété reste dans `diacamma/`. Les sources complémentaires conservent
leur organisation de paquets, modèles, migrations, vues, tests et documentation.

Sources des distributions : <https://pypi.org/project/diacamma-financial/>,
<https://pypi.org/project/lucterios-contacts/>,
<https://pypi.org/project/lucterios-documents/>.
